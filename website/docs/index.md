a2a holds the [A2A (Agent2Agent) protocol](https://github.com/a2aproject/A2A) v1.0.1 as an
executable specification in [ESS](https://github.com/beyond10x/ess). The specification is the
source: OpenAPI, AsyncAPI and JSON Schema documents and a Rust crate are generated from it, and
`task check` in the repository fails when any of them differs from what the specification
generates.

## How this site is made

Every page under Reference and every file under Downloads is generated by the repository's
`a2a-docs` crate: the specification pages by `ess generate --kind docs`, the others from `ess/`,
`upstream/` and `generated/`. `task docs-generate` rewrites them, and `task check` fails when one
of them is stale or edited by hand or when Reference or Downloads holds a file the crate does not
generate. Concepts and Guides are written by hand.

The repository is [beyond10x/a2a](https://github.com/beyond10x/a2a); its changes are in
[CHANGELOG.md](https://github.com/beyond10x/a2a/blob/main/CHANGELOG.md).
